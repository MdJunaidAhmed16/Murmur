## Local versus hosted

Same 10 clips twice, same pipeline settings (GPU TTS, clause-first chunk, speculate at 128 ms,
600 ms hold); only `MURMUR_BACKEND` differs. 20 answered turns each. p50 / p90 ms.

| Stage | Local (Qwen2.5-1.5B, vLLM, RTX 4060 Laptop) | Hosted (Claude Haiku 5.5 via OpenRouter) |
| --- | --- | --- |
| Model, first token | 118 / 160 | 989 / 1342 |
| Model, first chunk | 170 / 338 | 112 / 455 |
| Speech, first audio | 204 / 352 | 175 / 250 |
| **Time to first audio** | **756 / 1110** | **1652 / 2099** |

The hosted model's first token is ~870 ms slower: the network round trip to OpenRouter and on
to Anthropic, plus the model's own reasoning at `low` effort. A small model on the same GPU as
the microphone wins on latency by 2.2×; the hosted one is the smarter model and runs without
a GPU, which is what an always-on demo needs.

**Choosing the hosted model** (`scripts/hosted_probe.py`, 5 requests each, first token):

| Model | p50 | max | Price per 1M tokens in / out (OpenRouter list) |
| --- | --- | --- | --- |
| Claude Opus 5.5 | 2868 ms | 3702 ms | $4 / $20 |
| **Claude Haiku 5.5** | **898 ms** | 953 ms | $0.10 / $0.50 |

Haiku is the demo model: ~3× faster to first token and ~1/40 the price. Estimated (not
measured) cost: ~$0.0005 per conversational turn including background memory calls, so the
key's $3 cap covers on the order of thousands of turns.

## The demo video

53 seconds, recorded in headless Chrome against the local backend: a scripted synthetic voice
as the microphone, the page's own audio graph recorded so both voices stay in sync
(`scripts/record_demo/`). It shows memory written in the background, a `calculate` tool call,
an interruption cut in ~66 ms with only the heard words kept, and recall of both facts.

Recording it found a bug: asked *"What's my sister's name?"*, the 1.5B extractor invented
"Sport played - Cricket" and superseded the true fact. Questions are now stripped before
deciding whether a turn says anything about the user (unit-tested); the second take was clean.
A forget request ("Please forget my sister's name") lost its first words to an endpoint split
in both takes, so the video ends before it; listed under known issues.

## The public demo

- Cloud Run, scale to zero; CPU-only today (Whisper `base.en` + Kokoro on 4 vCPU, Claude Haiku
  as the brain), one L4 GPU once quota is granted (`GPU=1`, one flag).
- Per-visitor memory (`MURMUR_DEMO_MODE`): each browser's facts are private and ephemeral.
- One conversation at a time; a second visitor is told someone else is talking.
- Time to first audio on Cloud Run: TBD, to be measured after deploy. On this machine with 4
  CPU threads, `small.en` took 1295 ms for one sentence (hence `base.en`), Kokoro's first chunk
  422–766 ms.

## Security note

During the hosted run, `gate3.sh` printed its `MURMUR_*` settings, which included the
OpenRouter key, into a local log. It never reached git (`results/` is ignored; verified across
tracked files and history). The script now omits anything named like a secret, the log was
redacted, and the key should be rotated.

## What the ten days produced

A voice agent that answers in 756 ms p50 on a laptop GPU (from 2382 ms), lets you interrupt it
in 66 ms and keeps only what you heard, and remembers you across restarts with a memory layer
that never touches the turn path — with the evidence for each claim in R1–R3, and the failures
that shaped it written down alongside.
